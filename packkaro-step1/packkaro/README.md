# PackKaro – Step 1 Starter

Plain HTML + CSS + JavaScript. **No build tools, no installs** needed.

## Files
- `index.html` – the page structure
- `style.css` – the look
- `app.js` – the behaviour (dynamic source boxes, saving)
- `functions/api/hello.js` – a tiny server function (Cloudflare turns it into `/api/hello`)
- `ROADMAP.md` – the full plan

## Try it on your computer
Double-click `index.html`. Source boxes work. "Test server" will say no server found (normal locally).

## Put it online
Follow sections 2 and 3 of `ROADMAP.md` (GitHub, then Cloudflare Pages).
